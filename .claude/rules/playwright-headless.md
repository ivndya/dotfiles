# Playwright: только headless и только по требованию

Настроен ровно один MCP-сервер `mcp__playwright__*` — chromium в headless-режиме.
Отдельного headed-сервера больше нет (убран 2026-08-31, экономия ~0.7 GB ОЗУ:
каждая сессия Claude Code поднимала свой экземпляр).

С 2026-08-31 сервер вынесен из глобального `~/.claude.json` в
`~/.claude/mcp/playwright.json` и подключается флагом запуска: `cl pw`
(комбинируется с уровнем — `cl low pw`). Причина та же — за него платили все
сессии сразу: 9 одновременных сессий держали 1.5 GB, ~115 MB на сессию, при
том что браузер нужен в единицах случаев.

Если инструментов `mcp__playwright__*` в текущей сессии нет — они не сломаны,
сессия просто запущена без `pw`. Сказать об этом пользователю и предложить
перезапуск через `cl pw`, а не искать поломку в конфиге.

Причина отказа от headed: он оставлял в Dock и в ⌘Tab пустое окно
«Google Chrome for Testing», которое висело после завершения работы, а платили
за это все сессии сразу — даже те, что браузер не открывали ни разу.

Скриншоты, снапшоты страницы и весь остальной инструментарий одинаково работают
в headless — он ничего не ограничивает.

Если пользователь явно просит показать браузер («покажи браузер», «хочу видеть,
что происходит», «headed»), headless всё равно остаётся: отдать скриншот или
снапшот через `browser_take_screenshot` / `browser_snapshot`. Если нужно именно
видимое окно — вернуть сервер в `~/.claude.json`:

```json
"playwright-headed": {
  "type": "stdio",
  "command": "npx",
  "args": ["@playwright/mcp@latest", "--browser", "chromium"]
}
```

и закрывать браузер через `browser_close`, не оставлять висеть.
