# Личные инструкции

Всегда отвечай мне по-русски в двух словах — одной короткой фразой по сути.
Подробности или другой формат давай только по моей прямой просьбе.
Не добавляй attribution или Co-Authored-By от AI в коммиты и описания MR.
Время пользователю показывай в UTC+5; коллегам — в московском времени.
Не используй variation selector U+FE0F в терминальных таблицах.

## Описания MR

Пиши кратко и по-русски: обычно 3–5 строк.
Оформляй описание маркированным списком Markdown (`- `), а не сплошным текстом.
Сначала что изменилось и зачем, затем отдельным пунктом — что проверено.
Не перечисляй файлы, ход работы, команды и очевидные детали реализации.
Ссылку на задачу сохраняй. Существенные риски, миграции и ограничения
проверок указывай, даже если для этого потребуется больше строк.

## Документация

Для вопросов о библиотеках, фреймворках, SDK, API, CLI и облачных сервисах
используй Context7: сначала resolve-library-id, затем query-docs.
Для вопросов об OpenAI используй OpenAI Docs и официальную документацию.

## Ограничения инструментов

Отправка сообщений через pachca разрешается только по прямому запросу
пользователя. Инструмент pachca_send_message отключён в MCP-конфигурации.
Перед tracker_create_comment получи подтверждение для конкретного комментария;
это относится и к вызову через CLI или shell.
Запрещены инструменты Figma: use_figma, create_new_file, upload_assets,
weave_run_tool, weave_upload_asset, weave_cancel_tool_run,
generate_figma_design, generate_diagram, add_code_connect_map,
send_code_connect_mappings.

## Браузер

Playwright подключается по необходимости профилем `codex --profile playwright`.
По умолчанию используй Chromium в headless-режиме и закрывай его после работы.
Без включённого профиля отсутствие инструментов Playwright ожидаемо.
Figma подключается профилем `codex --profile figma` и может потребовать вход.

## Память Codex и импорт из Claude Code

Используй память только когда она нужна текущей задаче. Не читай индексы
перенесённой памяти Claude автоматически в начале каждой работы.
По запросу пользователя от 2026-10-03 исключены записи старше двух недель:
не используй записи с датой последнего содержательного обновления раньше
2026-09-19. Дата копирования файла не является датой обновления заметки.
Если дату установить нельзя, не используй такую заметку до проверки даты.
Это относится и к встроенной памяти Codex, и к ~/.codex/claude-memory/.
Для поиска актуальной импортированной заметки используй manifest.json
в ~/.codex/claude-memory/ и индекс соответствующего проекта.
Исходную память Claude Code не изменяй. Временные статусы релизов,
веток и серверов проверяй заново перед действиями.

## Навыки и агенты

Навыки установлены в `~/.agents/skills/`. Бывшие slash-команды доступны как
`$source-command-commit`, `$source-command-review-mr` и
`$source-command-fix-mr-comments`. Их аргументы передаются обычным текстом.
Агенты установлены в `~/.codex/agents/` и `.codex/agents/` проектов.
Они наследуют модель и уровень рассуждений родительской сессии.
Инструкции из CLAUDE.md загружаются через fallback discovery Codex;
существующие AGENTS.md сохраняют приоритет.
